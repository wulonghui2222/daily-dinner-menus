## 使用说明

食材分量按两人份设计，主食按实际食量调整。采用不放酒和料酒的做法，食材洗净、生熟分开、现做现吃；肉、鱼虾贝和蛋彻底做熟，鱼仔细去刺。图片与文字按原归档保留，具体做法请结合食材大小调整。

本仓库保存菜谱及菜单素材，不包含群聊、发送状态、账户配置或凭据。菜单为家常烹饪参考，不作为个体医学营养处方。
